JRK Analytics Design

Tokens, plain-CSS components, and React wrappers for analytics dashboards. One token layer feeds both stacks: Jinja templates link one stylesheet, the Next.js apps import the same tokens as a Tailwind v4 theme. Every color here passed an automated gate — nothing was eyeballed.

Pages

Foundations Color, type, spacing, radius, elevation, focus — with live contrast readouts. Components Buttons, forms, badges, tables, shell, modals, toasts, empty states. Charts Series palette, marks, legend, tooltip, table view, texture fallback. Dashboard A full page assembled from the library, in both themes.

How it is consumed

<button class="jrk-btn jrk-btn--primary">Run audit</button>
<span class="jrk-badge jrk-badge--good">Reconciled</span>

/* app/globals.css */

@import "@jrk/design/dist/jrk-tokens.css";
@import "@jrk/design/dist/jrk-theme.tailwind.css";

Both paths resolve to the same CSS custom properties, so a Tailwind utility and a jrk-* class produce the same color and both follow the theme toggle.

The rules the library enforces

Color is computed, not chosen. npm run validate runs the palette through a lightness band, a chroma floor, colorblind separation under simulated protanopia and deuteranopia, a normal-vision floor, and WCAG contrast — in both themes, against the real surfaces. It fails the build, not a review comment.
The series palette is never cycled. Eight slots in a fixed order; the order is the colorblind-safety mechanism. A ninth series folds into “Other” or facets into small multiples. seriesColor(8) throws rather than inventing a hue.
Color is never the only signal. Status badges ship an icon and a label. Deltas state their direction in text. Every chart has a table view. Three light-mode series hues sit below 3:1 by design — the visible value labels are the documented relief, and the validator cross-checks that the list of them in the tokens is not stale.
One axis, thin marks, recessive chrome. No dual-axis charts. Bars cap at 24px with a 4px data-end. Touching fills are separated by a 2px gap in the surface color, never by a stroke — a stroke adds ink that is not data.

Repo layout

tokens/tokens.json          source of truth — the only file you hand-edit
scripts/build-tokens.mjs    -> dist/ (CSS vars, Tailwind @theme, typed TS)
scripts/validate-colors.mjs the color gate — six checks + WCAG, both themes
scripts/check-css.mjs       brace balance, token typos, raw-hex discipline
css/                        plain-CSS library — works with no build step
react/src/                  React wrappers over the same class names
preview/                    this gallery — static, no build step
