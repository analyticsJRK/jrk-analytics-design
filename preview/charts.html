Charts

The data-viz layer. Every color below cleared an automated gate: a lightness band, a chroma floor, colorblind separation under simulated protanopia and deuteranopia, a normal-vision floor, and contrast against the real surface — in both themes. Run it yourself with npm run validate.

Series palette

Eight slots in a fixed order. The order is the colorblind-safety mechanism, not a style choice — neighbors are what touch in a stack or a line chart, so adjacent pairs are what the separation gate measures.

Never cycled. A ninth series is not a generated hue — it folds into “Other”, facets into small multiples, or takes a second encoding. seriesColor(8) throws instead of wrapping around.
Scatter and bubble cap at three series. There, any two marks can sit side by side, so the harder all-pairs test applies and only the first three slots clear it. That is a series cap, not a palette change — no ordering of eight can pass.

Line chart

Hover the plot — the crosshair and tooltip ship by default. An SVG chart is interactive; values the eye cannot read off the axis have to be reachable.

Stat tiles

When the data is a single headline number, a tile beats a one-bar chart. The delta names its comparison window — a percentage with no window means nothing.

Collected rent $4.21M up+3.1% vs last month
Occupancy 93.8% down−0.6pt vs last month
Delinquency rate 4.7% down−1.2pt vs last month
Work orders 1,284
Down is not always bad. Delinquency falling is good, so the tile is green while the arrow still points down. The component takes direction and interpretation as separate inputs and never assumes up means good. The direction is also stated in text for screen readers — the arrow glyph and the color are both reinforcement.

What the library will not do

No dual-axis charts. Two y-scales let the author choose the correlation by picking the scales. Two measures of different magnitude become two charts, small multiples, or values indexed to a common base.
No color by rank. A filter that changes the series count must not repaint the survivors — color follows the entity, so slot assignment is by identity and stays put.
No rainbow sequential ramps, no hue at a diverging midpoint. Sequential is one hue light→dark. Diverging is two hues with a neutral gray middle, so “nothing” reads as nothing.
No status color as a series color. When a series means good or bad — an error rate, a pass/fail — it wears status tokens. When it is just “series 4” it wears categorical. Never both in one chart.
No value label on every point. Labels work because they are sparing: the endpoint, the extreme, the one series the story is about. The axis, the legend, and the table view carry the rest.
